# Jenkins CI Pipeline – Selenium Automation Project

## Project Overview
This project demonstrates Continuous Integration (CI) using Jenkins to automatically run Selenium TestNG test cases on every Git commit.

## Tools Used
- Jenkins
- GitHub
- Maven
- Selenium WebDriver
- TestNG
- Java

## Test Scenarios Implemented
- Valid Login Test
- Invalid Login Test
- Empty Credentials Test

## Jenkins Pipeline Stages
1. Clone GitHub Repository
2. Build the Project using Maven
3. Execute Selenium TestNG Tests
4. Publish Test Results in Jenkins
